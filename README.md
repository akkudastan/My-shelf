# ✈️ Фиксация Посадки / Boarding Logger

[RU] | [KZ] | [EN]

---

## 🇷🇺 Русский

Веб-приложение для быстрых отметок времени на этапах посадки пассажиров на рейс с поддержкой генерации отчетов.

### 🚀 Возможности
* **Мультиязычность:** Переключение интерфейса на RU, KZ и EN.
* **Живые часы:** Отображение местного времени и точного UTC.
* **Типы посадки:** Переключение режимов (Гейт / Дальняя стоянка).
* **Динамические кнопки:** Добавление неограниченного количества отметок «Отметить».
* **История действий:** Поддержка отмены и возврата действий (Undo/Redo).
* **Быстрый экспорт:** Копирование отдельных строк или итогового отчета в буфер обмена.

---

## 🇰🇿 Қазақша

Рейске жолаушыларды отырғызу кезеңдерінде уақытты жылдам белгілеуге және есептерді қалыптастыруға арналған веб-қолданба.

### 🚀 Мүмкіндіктер
* **Көптілділік:** Интерфейсті RU, KZ және EN тілдеріне ауыстыру.
* **Тікелей сағат:** Жергілікті уақыт пен дәл UTC көрсету.
* **Отырғызу түрлері:** Режимдерді ауыстыру (Гейт / Қашықтағы тұрақ).
* **Динамикалық батырмалар:** Қосымша «Белгілеу» оқиғаларын шектеусіз қосу.
* **Әрекеттер тарихы:** Әрекеттерді жою және қайтару (Undo/Redo).
* **Жылдам экспорт:** Жеке жолдарды немесе толық есепті көшіру.

---

## 🇬🇧 English

A web application for fast timestamping during flight boarding stages with automated report generation.

### 🚀 Features
* **Multilingual:** Interface switching between RU, KZ, and EN.
* **Live Clock:** Real-time local and exact UTC display.
* **Boarding Types:** Toggle modes between Gate and Remote Stand.
* **Dynamic Buttons:** Add unlimited custom "Mark" timestamp entries.
* **Action History:** Support for Undo and Redo functions.
* **Quick Export:** One-click copy for single lines or full boarding reports.

---

## 🛠 Запуск / Launch
Для запуска достаточно открыть файл `index.html` в любом браузере.  
Simply open `index.html` in any browser to run the app.
